# Домашнее задание 4

Запуск из этой папки: `go run .`.
Проверка: `go test ./...`.

Интерфейс и общая логика вывода находятся в `channel.go`, реализации каналов — в `email.go` и `push.go`, рассылка — в `delivery.go`, пример запуска — в `demo.go`.

Обработка паники вынесена в `recovery.go`, типы ошибок — в `failures.go`.

Основа решения и проверочные тесты: https://github.com/TuHeKocmoc/x5go/tree/main/HW4. Код переработан с сохранением поведения.
